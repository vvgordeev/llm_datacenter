Разные базовые модели — разная специализацияDifferent base models, different strengths

Сравнивая базовые модели [01:41], Герк отмечает, что Dots работает на GPT-6 Astra — более мощной модели для сложных задач: кодинга, разработки ПО, многошаговой автоматизации. Muse Spark 1.3, напротив, сильнее в общей работе со знаниями и рутинной помощи, но не предназначена тягаться с Astra на инженерных задачах. Разница в базовых моделях задаёт и разницу в сценариях использования, которую видео разбирает дальше. Comparing the underlying models [01:41], Herk notes that Dots runs on GPT-6 Astra — the stronger model for hard tasks like coding, software development and multi-step automation. Muse Spark 1.3, by contrast, is better at general knowledge work and routine assistance but isn't built to compete with Astra on engineering tasks. That gap in base models drives the gap in use cases the rest of the video walks through.

Muse выигрывает интерфейсом, Dots — интеграцией с рабочими инструментамиMuse wins on interface, Dots on integrating with work tools

Герк показывает библиотеку артефактов Muse и её редактируемые файлы памяти — так называемые «soul files», которые пользователь может открыть и поправить вручную [02:29], а также удобные для нетехнического пользователя функции — постановку целей, генерацию идей и настраиваемую ленту [09:38]. У Dots сильная сторона — не интерфейс, а бесшовная интеграция в Slack для командной коммуникации [04:43]: агент встроен туда, где технические команды и так работают, а не требует отдельного приложения. Herk shows Muse's artifact library and its editable memory files — the so-called "soul files" a user can open and edit by hand [02:29] — plus features aimed at non-technical users: goal-setting, idea generation, and a customizable feed [09:38]. Dots' strength isn't the interface — it's seamless Slack integration for team communication [04:43]: the agent sits where technical teams already work instead of demanding a separate app.

Главная слабость Dots: не держит собственное расписание задачDots' core weakness: it doesn't track its own task schedule

Самая практичная часть ролика — список реальных ограничений Dots на первой неделе использования [11:35]: агент путается в уже запланированных задачах и не всегда понимает собственный рабочий процесс — то берётся повторно за то, что уже сделал, то теряет контекст запланированного на потом. Герк подводит итог так [13:29]: выбор между Dots и Muse — это не вопрос «какой агент лучше», а вопрос существующего рабочего процесса пользователя. Технической команде, уже живущей в экосистеме ChatGPT/Codex, Dots встраивается без трений; тем, кому нужен более доступный личный помощник с опорой на соцсети Meta и мягкий, настраиваемый интерфейс — ближе Muse. The most practical part of the video is Herk's running list of Dots' real-world limitations in its first week [11:35]: the agent gets confused about tasks it has already scheduled and doesn't always track its own workflow — redoing work it already finished, or losing track of what it deferred for later. Herk's bottom line [13:29]: choosing between Dots and Muse isn't about which agent is "better" — it's about the user's existing workflow. A technical team already living in the ChatGPT/Codex ecosystem gets Dots with no friction; anyone wanting a more accessible personal assistant with Meta's social integrations and a softer, customizable interface is better served by Muse.
