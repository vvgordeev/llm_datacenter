Дальше — центральный кусок видео: на глазах у зрителя Astra за несколько минут собирает клон 3D-игры «Megabonk» и интерактивный симулятор мира «Orbis» по текстовым описаниям [07:02]. Автор подчёркивает именно скорость многошагового цикла (написать код → запустить → увидеть баг → исправить) без ручного вмешательства между шагами — то, что раньше требовало десятков отдельных запросов. The first practical check is the BuseyBench test: the model draws an SVG portrait from a photo in a single prompt, and Wolfe compares the output to previous models' attempts [05:26]. Then comes the video's centerpiece: on screen, Astra assembles a "Megabonk" 3D game clone and an interactive world simulator called "Orbis" from text prompts in a matter of minutes [07:02]. What he flags specifically is the speed of the multi-step loop (write code → run it → spot the bug → fix it) with no manual intervention between steps — something that used to take dozens of separate prompts.

Управление 3D-редакторами напрямуюDirectly driving 3D tools

Самая наглядная демонстрация — Astra напрямую управляет Blender и Unreal Engine, создавая, риггая и анимируя 3D-модель волка от начала до конца, без промежуточных экспортов вручную [11:32]. Это прямое следствие заявленного скачка на бенчмарках компьютерного управления: модель не просто пишет код, который потом запускают отдельно, а сама кликает, тащит и настраивает параметры внутри профессионального интерфейса — то есть управляет тем же инструментом, которым пользуется 3D-художник-человек, а не специальным API поверх него. The most vivid demo is Astra directly driving Blender and Unreal Engine, creating, rigging, and animating a 3D wolf model start to finish with no manual exports in between [11:32]. This is a direct consequence of the claimed computer-use benchmark jump: the model isn't just writing code that gets run separately — it's clicking, dragging, and adjusting parameters inside the professional interface itself, operating the same tool a human 3D artist would use rather than a special API layered on top.
