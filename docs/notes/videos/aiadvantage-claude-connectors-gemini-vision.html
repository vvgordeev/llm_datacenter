Agentic Vision в Gemini 3 Flash: зрение через выполнение кодаAgentic Vision in Gemini 3 Flash: vision through code execution

Центральная техническая демонстрация ролика — Agentic Vision в Gemini 3 Flash [08:55]: вместо того чтобы просто «посмотреть» на изображение и описать его одним проходом, модель пишет и выполняет код, чтобы разобрать картинку — выделять области, считать объекты, перепроверять детали, — и за счёт этого даёт более глубокий и точный анализ, чем обычное распознавание изображений. Пожани показывает это на конкретных примерах, а не только пересказывает анонс. The video's central technical demo is Agentic Vision in Gemini 3 Flash [08:55]: instead of just "looking" at an image and describing it in one pass, the model writes and runs code to take the picture apart — cropping regions, counting objects, double-checking details — which gets it to a deeper, more precise analysis than plain image recognition. Pogany demonstrates this with concrete examples rather than just restating the announcement.
