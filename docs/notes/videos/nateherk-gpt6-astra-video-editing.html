Nate Herk hands GPT-6 Astra, running in the Codex desktop app, a raw recording and a plain-English description of what should happen on screen [01:26]: the agent transcribes the audio itself, cuts mistakes and filler, adds motion graphics and B-roll, writes subtitles, and syncs audio to picture — taking over the whole editing cycle that used to need a separate editor.

Метод: 5-шаговый пайплайн монтажаThe method: a 5-step editing pipeline

Ядро видео — пятишаговый процесс, который Херк выкладывает пошагово [11:24]: (1) транскрипция исходника через ElevenLabs с получением точного текста и таймингов [13:42]; (2) разметка текста самим агентом — где вырезать паузы и оговорки; (3) генерация плана монтажа (motion graphics, b-roll, титры) на основе этой разметки; (4) сборка ролика инструментами, которые агент вызывает сам, без ручной работы в таймлайне видеоредактора; (5) проверка результата и точечная доработка по обратной связи автора. Отдельно он показывает, как задать агенту детальные инструкции для вступительного ролика в духе презентаций Apple [16:47] — от таймингов появления текста до стиля переходов. The video's core is a five-step process Herk lays out explicitly [11:24]: (1) transcribe the raw footage via ElevenLabs to get exact text and timings [13:42]; (2) have the agent itself mark up the transcript for where to cut pauses and filler; (3) generate an edit plan (motion graphics, B-roll, captions) from that markup; (4) assemble the cut using tools the agent calls on its own, with no manual timeline work in an editor; (5) review the result and make targeted fixes from the creator's feedback. He separately shows how to give the agent detailed instructions for an Apple-keynote-style intro [16:47] — down to text-reveal timing and transition style.

Побочный результат: короткие ролики из того же материалаA side result: short-form clips from the same footage

После сборки основного видео Херк показывает, как этот же агент из того же исходника нарезает несколько коротких вертикальных роликов (reels) для соцсетей — выбирая наиболее самодостаточные по смыслу фрагменты и переоформляя их под формат коротких видео [03:04]. Это ключевая экономия метода: одна запись и один прогон агента дают одновременно длинное видео и пакет коротких нарезок, вместо того чтобы монтировать каждый формат отдельно. After assembling the main video, Herk shows the same agent cutting several short vertical clips (reels) for social media from the same source footage — picking the most self-contained segments and reformatting them for short video [03:04]. That's the method's key saving: one recording and one agent run produce both the long-form video and a batch of short cuts, instead of editing each format separately.

ОграниченияLimitations

Метод остаётся зависимым от качества исходной начитки (агент вырезает оговорки, но не генерирует контент за автора) и от доступа к GPT-6 Astra и платному ElevenLabs; Херк не утверждает, что итоговый монтаж не требует вообще никакой ручной доводки — скорее, что рутинная часть (транскрипция, черновая сборка, субтитры, b-roll) перестаёт требовать отдельного редактора. The method still depends on the quality of the original recording (the agent trims filler, it doesn't generate content on the presenter's behalf) and on access to GPT-6 Astra and a paid ElevenLabs plan; Herk doesn't claim the final cut needs zero manual polish — rather, that the routine part (transcription, rough assembly, captions, B-roll) stops requiring a dedicated editor.
