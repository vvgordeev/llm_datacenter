Метод: зачем нужны Delta Attention и почему модель «построена для циклов»The method: what Delta Attention is for, and why the model is "built for loops"

Центральная часть видео [01:46] объясняет архитектуру MoE на пальцах: вместо того чтобы прогонять каждый токен через всю сеть, модель выбирает узкое подмножество «экспертов» под конкретный токен — отсюда и разрыв между общим размером (2,8Т) и активными параметрами (~50 млрд). Далее [03:45] автор подробно разбирает Kimi Delta Attention (KDA) и Attention Residuals — механизмы, которые держат стоимость внимания линейной даже на контексте в миллион токенов. Практический вывод, который выводит автор: модель «построена для циклов» — то есть переиспользует уже посчитанное для повторяющихся частей контекста вместо пересчёта заново, из-за чего многошаговые агентные рабочие процессы (когда одна и та же история диалога прогоняется через десятки итераций) становятся на порядок дешевле, чем на архитектурах без такой оптимизации. The video's core section [01:46] explains the MoE architecture plainly: instead of running every token through the whole network, the model routes each token to a narrow subset of "experts" — hence the gap between total size (2.8T) and active parameters (~50B). It then walks through [03:45] Kimi Delta Attention (KDA) and Attention Residuals — mechanisms that keep attention cost linear even at a million-token context. The host's practical takeaway: the model is "built for loops" — it reuses prior computation for repeated parts of the context instead of recomputing it, which makes multi-step agentic workflows (where the same conversation history gets re-run across dozens of iterations) an order of magnitude cheaper than on architectures without that optimization.

The video's value is that it doesn't stop at reciting architectural innovations — it immediately tests them in practice via an open, reproducible tool viewers can run themselves. The limitation is that the comparison rests on two specific, fairly small tasks and on the models' hosted APIs rather than self-hosted K3 weights [18:26]; the price-to-result conclusions may not carry over directly to longer agentic sessions or to self-hosted inference with different economics.
