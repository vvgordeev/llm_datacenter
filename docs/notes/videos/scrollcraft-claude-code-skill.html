Метод: интервью → активы → живая сборка → проверкаThe method: interview → assets → live build → verification

Дальше Claude либо использует уже готовые активы заказчика, либо генерирует фото- и видео-материалы через интеграцию с kie.ai, закрывая пробелы там, где готовых изображений нет [00:48]. Rather than forcing one visual template, the skill is built around design principles — spacing, typography, overall aesthetic — and opens with an interactive interview: what the business is, what the user journey should look like, what mood the site needs to convey [00:48]. From there, Claude either works with the client's existing assets or generates photo and video material through a kie.ai integration to fill gaps where none exist [00:48]. Ключевая часть метода — не первый результат, а цикл проверки: скилл сам делает скриншоты собранной страницы на разных этапах прокрутки и ищет дефекты (пустые зоны прокрутки, проблемы с контрастом, незагрузившиеся активы), после чего уточняет вёрстку по этой обратной связи, а не по единственному проходу генерации [09:12]. The core demo is a live redesign of the AI Automation Society site: he gives Claude a brief, it generates assets via kie.ai, and assembles a first version of the site [03:44]. The key part of the method isn't the first output but the verification loop: the skill screenshots the built page at different scroll points itself and checks for defects — dead scroll zones, contrast problems, unloaded assets — then refines the layout from that feedback instead of a single generation pass [09:12].

Когда это применимо и что скилл сознательно ограничиваетWhen it applies, and what the skill deliberately constrains

Херк подчёркивает, что подход годится для одностраничных презентационных сайтов — услуг, продуктов, личных брендов, — там, где нужен эффект «премиального» впечатления, а не для сложных многостраничных веб-приложений. Ограничение вшито и в сам дизайн-процесс: набор из восьми «грамматик страницы» и жёсткий «список отказов» (типовые ИИ-клише в дизайне под запретом), максимум два шрифтовых семейства и правило одного главного визуального пика на странице — всё это сознательно сужает пространство решений, чтобы результат не выглядел типовым ИИ-лендингом, а не потому что инструмент не умеет больше. Herk stresses the approach fits single-page presentation sites — services, products, personal brands — where the goal is a "premium" impression, not complex multi-page web applications. The constraint is built into the design process itself: a set of eight "page grammars" and a strict "refuse list" (common AI-design clichés are off-limits), a two-font-family cap, and a rule of one engineered visual peak per page — all of it deliberately narrows the solution space so the output doesn't read as a generic AI landing page, rather than the tool being unable to do more.
