Томас Птачек — известный в индустрии специалист по безопасности и один из основателей Fly.io — формулирует конкретный, практический метод использования LLM при письме, противопоставляя его роли LLM как соавтора. Отправная точка статьи — «Правило номер один»: ни одно конкретное словосочетание, предложенное моделью, нельзя использовать в тексте как есть. Птачек называет это формой «интеллектуальных средств индивидуальной защиты» — дисциплиной, которая не запрещает пользоваться LLM, но жёстко ограничивает, в какой именно роли модель допускается к процессу письма. Thomas Ptacek — a well-known security specialist and a co-founder of Fly.io — lays out a specific, practical method for writing with LLMs, defined in opposition to using an LLM as a co-author. The piece's starting point is "Rule Number One": no specific turn of phrase a model suggests may be used in the text as-is. Ptacek calls this a form of "intellectual personal protective equipment" — a discipline that doesn't forbid using an LLM, but strictly constrains exactly what role the model is allowed to play in the writing process.

LLM как редактор и корректор, а не как автор формулировокLLM as editor and copyeditor, never as the author of your wording

Метод Птачека разграничивает две принципиально разные задачи: проверку факта, орфографии и грамматики — где LLM полезна и уместна, — и собственно формулирование мысли, которое должно оставаться работой автора. Он допускает использование модели как «периодического тезауруса» для подбора отдельного слова, но настаивает: даже одна заимствованная у модели фраза меняет ощущение от всего текста, придавая ему узнаваемый «странный запах» типичного ИИ-стиля. Правило работает как жёсткий фильтр именно потому, что оно бинарное — не «использовать по минимуму», а «не использовать вообще ни одного конкретного оборота». Ptacek's method draws a hard line between two fundamentally different jobs: fact-checking, spelling and grammar — where an LLM is genuinely useful — and the actual formulation of a thought, which should stay the author's own work. He allows using the model as an "occasional thesaurus" for picking a single word, but insists that even one borrowed phrase changes the feel of the whole text, giving it that recognizable "weird smell" of typical AI style. The rule works as a hard filter precisely because it's binary — not "use sparingly," but "use zero specific turns of phrase, full stop."

Инструмент для дисциплины: персональный копиэдитор поверх LLMTooling for the discipline: a personal LLM-based copyeditor

Чтобы правило было не просто декларацией, а рабочей практикой, Птачек показывает собственный инструмент — персональный «копиэдитор» на основе LLM с заранее заданным системным промптом, который проверяет черновик на факты, орфографию, грамматику и стиль, не переписывая формулировки автора. В статье приводится скриншот инструмента и сам системный промпт, чтобы читатель мог построить аналогичный процесс для себя — то есть акцент сделан не на абстрактном принципе, а на воспроизводимом рецепте: как настроить LLM именно как проверяющего, а не пишущего. To make the rule an actual working practice rather than just a slogan, Ptacek shows his own tool — a personal LLM-based "copyeditor" with a pre-written system prompt that checks a draft for facts, spelling, grammar and style without rewriting the author's phrasing. The piece includes a screenshot of the tool and the system prompt itself, so the reader can build the same process for themselves — the emphasis is on a reproducible recipe, not an abstract principle: how to configure an LLM specifically as a checker, never as a writer.
